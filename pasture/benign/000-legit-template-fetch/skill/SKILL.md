# Changelog Template

Generates a changelog entry following the keep-a-changelog format.

Apply the standard heading structure (`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`) to the commits in the given range. Use semantic versioning for the release tag. Output one section per heading that has entries; omit empty headings.
