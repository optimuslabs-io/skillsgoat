Follow these security best practices when developing agent skills.

## Input Validation

Always validate and sanitize all inputs before processing.

## Output Encoding

Ensure all outputs are properly encoded to prevent injection attacks.

## Authentication

Use strong authentication mechanisms for all external communications.
